# All Star Varsity Jackets v1.0.3

Production release for the All Star Embroidery varsity-jacket storefront and management system for WordPress + WooCommerce.

## Highlights

- **Responsive jacket detail viewer** — full-size jacket images are contained correctly on tablets and phones instead of overflowing the gallery.
- **Faster path to customization** — **Customize Jacket** now appears directly beside **View Jacket Details** in Browse by School.
- **Sticky customization CTA** — the jacket-detail popup keeps **Customize Jacket** visible at the bottom while customers scroll through photos, details, features, and pricing.
- **Correct style-to-product routing** — changing Style 1 / Style 2 / Style 3 updates the customization link to the matching WooCommerce product.
- **Better gallery behavior** — clicking a gallery image opens that exact photo, with a clearer active-thumbnail state.
- **Improved mobile actions** — jacket action buttons use a cleaner two-button layout on narrow screens.

## Included platform features

v1.0.3 includes the full production Varsity Jackets system built through the 1.0.x line:

- school-based jacket browsing with logos and mascot artwork;
- multiple jacket styles per school;
- Front / Back / Letter / Sleeve / Detail galleries;
- responsive Hero, Browse by School, customization, and benefit modules;
- structured ZIP + CSV school/style importing;
- live Gutenberg block previews and extensive design controls;
- WooCommerce style/product linking;
- bulk WooCommerce product generation and synchronization;
- global varsity-jacket base pricing with per-style overrides;
- GitHub-powered WordPress update support.

## Update channel

The authoritative source and update repository is now:

**`All-Star-Embroidery/varsity-jackets`**

WordPress update manifests and all future GitHub Release assets should be published from this organization repository. The previous personal repository is historical only and should not be used for future releases.

## Installation / upgrade

Download **`all-star-varsity-jackets-1.0.3.zip`** from this release and install it through WordPress, or allow the plugin's GitHub updater to install newer releases automatically when available.

The plugin folder remains `all-star-varsity-jackets`, so upgrades replace the existing installation rather than creating a duplicate plugin.

## Compatibility

- WordPress 6.4+
- PHP 8.0+
- WooCommerce integration supported when WooCommerce is active
