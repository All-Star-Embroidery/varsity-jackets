# All Star Varsity Jackets v1.0.3

## Changes

- Fixed tablet and phone jacket-detail images overflowing the gallery by containing media and capping viewport height.
- Added **Customize Jacket** beside **View Jacket Details**.
- Style changes now update the correct WooCommerce product/link used by the customization flow.
- Made the popup CTA sticky at the bottom and added the starting price.
- Gallery thumbnail clicks now open the selected photo.
- Improved active-thumbnail styling.
- Mobile action buttons now use an even two-button row.

## Distribution

- Authoritative repository: `All-Star-Embroidery/varsity-jackets`
- WordPress package: `all-star-varsity-jackets-1.0.3.zip`
- Release tag: `v1.0.3`
- GitHub Actions publishing is manual-only to conserve Actions minutes.

## Compatibility

- WordPress 6.4+
- PHP 8.0+
- WooCommerce remains optional where supported by the plugin.
