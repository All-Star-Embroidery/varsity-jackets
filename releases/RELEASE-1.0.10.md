# All Star Varsity Jackets v1.0.10

## Changes

- Fixed the dedicated jacket product page so the full jacket image always remains visible instead of being cropped by image scaling at certain viewport sizes.
- Capped jacket image scaling at 100% and kept `object-fit: contain` across desktop, tablet, and mobile.
- Reworked the product-page visual language away from uniform rounded SaaS-style cards.
- Sharpened primary surfaces to a 4px maximum radius, buttons/thumbnails to 3px, and removed soft card/button shadows.
- Replaced floating-card treatment with hairline borders and flatter printed-retail/document styling.
- Preserved All Star navy/gold branding, responsive behavior, gallery controls, and the existing product-page customization controls.
