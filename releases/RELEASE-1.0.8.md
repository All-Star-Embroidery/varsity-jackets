# All Star Varsity Jackets v1.0.8

## What's new

- Added a new **Varsity Jacket Product Page** Gutenberg block for dedicated jacket product layouts.
- The block automatically detects the linked WooCommerce varsity jacket product on the frontend and stays hidden on unrelated products.
- Added a gallery-first product layout with school identity, jacket style, starting price, jacket details, features, customization options, and a call-to-order section.
- Added strong pricing clarification that the displayed price is the base jacket price and that lettering, patches, embroidery, names, numerals, and other customizations are additional.
- Added configurable tap-to-call or contact-link ordering CTA instead of an online-purchase-focused layout.
- Added extensive block controls for content, visibility, gallery sizing, spacing, image scale, corner radius, colors, mobile gallery height, and customization copy.
- Added live server-side Gutenberg preview using a linked jacket product.
- Added a responsive thumbnail gallery and compact mobile customization layout.

## Using the new block

Add **Varsity Jacket Product Page** from the **All Star Embroidery** block category to the product template/page you want to use for jackets. On a real linked jacket product, the block automatically pulls the school, style, WooCommerce starting price, images, gallery, description, and features.

Set the store phone number in the block controls to turn the order CTA into a tap-to-call button.
