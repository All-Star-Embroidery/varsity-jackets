# All Star Varsity Jackets v1.0.9

## What's new

- Automatically routes WooCommerce products linked to Varsity Jacket styles to the dedicated Varsity Jacket Product Page layout.
- Leaves all non-varsity WooCommerce products on the normal Single Product template.
- Adds an editable **Product Page Template** under All Star Jackets so the shared jacket layout can be customized with Gutenberg blocks.
- Keeps linked jacket products as normal **Simple products**; no custom WooCommerce product type is required.
- Disables online purchasing for linked varsity jacket products and uses the call-to-order product experience instead.
- Adds a product-editor status box showing whether the Varsity Jacket template is active, plus a direct link to edit the shared layout.

## How it works

Any WooCommerce product linked to an All Star Varsity Jacket style is detected automatically. Its public product URL uses the dedicated jacket template and the shared **Varsity Jacket Product Page** block layout. Other WooCommerce products are untouched.
