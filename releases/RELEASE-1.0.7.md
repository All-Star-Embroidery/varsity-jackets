# All Star Varsity Jackets v1.0.7

A small UX refinement to keep **Browse by School** more compact and reduce unnecessary vertical scrolling.

## Changes

- Reduced the height of the selected jacket gallery on desktop and laptop screens.
- Slightly reduced supporting gallery-tile heights so more of the school/style experience fits in one viewport.
- Preserved `object-fit: contain` so jackets are never cropped just to save space.
- Kept tablet/mobile galleries large enough to tap and inspect comfortably while avoiding oversized imagery.
- Leaves the jacket-detail popup sizing unchanged; this update only compacts the inline Browse by School gallery.
