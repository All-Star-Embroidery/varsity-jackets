# All Star Varsity Jackets v1.0.13

This release keeps the product-page jacket gallery in **Scale to fit** mode, but prevents tall jacket photography from taking over the page.

## Changes

- Keeps the entire jacket visible without cropping.
- Caps the main jacket image to a responsive medium size based on the current viewport.
- Desktop jacket images top out at a comfortable medium presentation instead of expanding to full natural width.
- Tablet and phone images use smaller viewport-aware caps to reduce unnecessary scrolling.
- Short laptop windows get an additional height safeguard.
- The existing Jacket Image Size control still allows further reduction inside the responsive gallery.

The gallery remains responsive and does not return to fixed desktop/mobile pixel-height controls.
