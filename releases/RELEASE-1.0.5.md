# All Star Varsity Jackets v1.0.5

## Changes

- Clarified every customer-facing varsity-jacket price inside the Varsity Jackets experience as a **Starting at** price.
- Added **Starting at** directly above the price in the jacket-detail popup, matching the existing selected-style and sticky-action pricing treatment.
- Preserved WooCommerce's actual product price values; this release only improves pricing language so customers understand customization can increase the final jacket total.
- Added styling for the modal price label so the hierarchy remains clear on desktop, tablet, and mobile.

## Pricing intent

The listed jacket price is the base jacket price. Chenille, embroidery, lettering, patches, names/numerals, and other customization choices may increase the final price.

## Compatibility

- WordPress 6.4+
- PHP 8.0+
- WooCommerce integration supported when WooCommerce is active
